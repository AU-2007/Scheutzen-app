Für alle

Zu einem Termin zu- oder absagen
  1. Unter Übersicht stehen deine Termine dieser Woche, unter Termine alle weiteren.
  2. Bei einem Wettkampf: Termin antippen → Zusage, Vielleicht oder Absage.
  3. Bei einem Training: Zusage, Später (du kommst nach) oder Absage. Gibt es zwei Bereiche (z. B. LG und KK), kannst du deinen Wunsch wählen.
  4. Du kannst deine Antwort jederzeit ändern. Ist ein Training voll, ist die Zusage gesperrt.

Offene Termine ohne Antwort zählt die Übersicht oben als „zu erledigen“.

Termine automatisch im Handy-Kalender
  1. Profil → Termine im Handy-Kalender → Kalender verbinden.
    2. {% if platform == 'apple' %}
  2. Zum Kalender hinzufügen tippen → Abonnieren. Fertig.
  3. Tipp: Einstellungen → Kalender → Accounts → Datenabgleich auf Stündlich.
    4. {% else %}
  4. Android/Samsung: Mit Google-Kalender verbinden → Hinzufügen.
  5. Wichtig: In der Google-Kalender-App ☰ → Einstellungen → ggf. „Mehr anzeigen“ → den neuen Kalender antippen → Synchronisieren einschalten. Sonst bleibt der Kalender auf dem Handy leer.
  6. iPhone: Zum Kalender hinzufügen → Abonnieren.
    7. {% endif %}

Zusagen erscheinen automatisch, Absagen verschwinden. Google holt neue Termine nur alle paar Stunden. Sofort geht es mit dem Knopf „📅 In meinen Kalender eintragen“, der nach jeder Zusage erscheint. Im Profil steht, wann dein Kalender zuletzt abgerufen hat.

Fahrgemeinschaft bei Auswärtswettkämpfen
  1. Auswärtswettkampf öffnen → Abschnitt Fahrgemeinschaft.
  2. Ich fahre (mit freien Plätzen im Auto), Brauche Mitfahrt (optional bei wem) oder Eigene Anreise.
  3. Alle sehen, wer fährt und wo noch Plätze frei sind.
Profil, Profilbild, Darstellung, Passwort
  1. Oben rechts auf deinen Namen → Mein Profil & Einstellungen.
  2. Dort: Statistik, Profilbild, Darstellung (hell/dunkel, Farbe) und Passwort ändern.

Passwort vergessen? Der Admin kann ein neues setzen. Danach wirst du auf allen Geräten abgemeldet.

Training

{% if is_trainer %}
Feste Trainingszeiten anlegen
  1. Termine → Trainingszeiten.
  2. Wochentag, Uhrzeit, Ort und Anzahl Stände eintragen. Mit zweitem Bereich (z. B. KK) gibt es eine eigene Ständezahl.
  3. Optional Gruppen wählen (z. B. Jugend). Dann sehen das Training nur diese Gruppen, sonst alle.
  4. Anlegen. Das Training erscheint ab jetzt jede Woche bei allen.
Sondertraining anlegen
  1. Unter Termine → + Sondertraining.
  2. Datum, Uhrzeit, Stände und ggf. eine Notiz eintragen → Sondertraining anlegen.
{% endif %}
Training ausfallen lassen
  1. Das Training unter Termine öffnen.
  2. Training ausfallen lassen, optional mit Grund → Als ausgefallen markieren.
  3. Alle sehen es als ausgefallen; aus Handy-Kalendern verschwindet es beim nächsten Abgleich. Rückgängig: Training findet doch statt.

Mannschaft & Wettkampf

{% if is_admin %}
Neue Mannschaft anlegen Admin
  1. Mannschaften → + Neue Mannschaft.
  2. Name, Disziplin, Liga, Saison und Mannschaftsführer wählen → Speichern.
  3. Der Mannschaftsführer kann die Mannschaft danach selbst verwalten.
{% endif %}
Schützen in die Mannschaft holen, Stamm und Ersatz
  1. Mannschaft öffnen → Abschnitt Schützen → Person wählen, Stamm oder Ersatz → Hinzufügen.
  2. Auf „Stamm“/„Ersatz“ tippen schaltet um. Entfernen über das ✕.
Wettkampftermine aus dem RWK-Onlinemelder übernehmen
  1. Im RWK-Onlinemelder den Kalender der Liga als .ics herunterladen.
  2. Mannschaft öffnen → Wettkampfplan importieren → Datei wählen.
  3. Die App sucht deine Mannschaft (z. B. „SV Eisenbach 3“) heraus. Stimmt sie nicht, oben die richtige wählen.
  4. Termine prüfen → Ausgewählte speichern. Gegner werden auf Wunsch gleich mit angelegt.

Falsch importiert? Auf derselben Seite unten: importierte Termine entfernen (nur Termine ohne Ergebnis).

Einzelnen Wettkampf anlegen oder verlegen
  1. Mannschaft öffnen → + Wettkampf → Datum, Uhrzeit, Gegner, Heim/Auswärts, Ort, Treffpunkt.
  2. Verlegen: Wettkampf öffnen → Termin verlegen → neues Datum → Verlegung beantragen. Ist sie bestätigt: Bestätigt, Termin ändern.
Aufstellung festlegen
  1. Wettkampf öffnen. Du siehst, wer zu-, ab- oder noch nicht geantwortet hat.
  2. Schützen anhaken → Aufstellen. Die Reihenfolge ist die Paarung.
  3. Fehlt jemand: Ersatz aus anderer Mannschaft oder eine Aushilfe eintragen.
Auswechseln nach RWK-Ordnung (Einsätze, Bindung)
  1. Die App zählt bei jeder Aufstellung die Einsätze jedes Schützen in der Saison (alle Mannschaften derselben Disziplin) und zeigt sie an, z. B. „4/10 Einsätze“.
  2. Bindung (VII.2/3): Wer mehr als zweimal in höheren Mannschaften geschossen hat, ist an die unterste dieser höheren Mannschaften gebunden. Die App warnt rot, wenn er tiefer aufgestellt wird.
  3. Höchstens 10 Wettkämpfe pro Saison (bei Gruppen mit 7 Mannschaften 12; einstellbar unter Mannschaft → Bearbeiten).
  4. Welche Mannschaft höher ist: Zahl im Namen („LG 1“ über „LG 2“) oder Rang im Verein unter Mannschaft → Bearbeiten.
  5. Jede Saison von vorn: Die Zählung beginnt automatisch am 1. August neu, auch Anpassungen gelten nur für ihre Saison.
  6. Überschreiben: Mannschaft öffnen → Einsätze Saison … → beim Schützen Anpassen: Einsätze außerhalb der App (z. B. vor einem Vereinswechsel) dazuzählen, Bindung aufheben oder von Hand festlegen, mit Notiz. „Automatisch zählen“ macht es rückgängig.
  7. Auf-/Abstiegskämpfe beim Wettkampf anhaken: Sie zählen nicht mit.

Bei einem Verstoß wird das Ergebnis des Schützen gestrichen (VII.5). Die App warnt nur und verbietet nichts. Einsätze bei einem früheren Verein oder in höheren Ligen außerhalb der App bitte über „Anpassen“ nachtragen.

Gegnerschützen, Standplan und DISAG-Datei
  1. Wettkampf öffnen → Gegnerschützen eintragen (aus der Gegnerliste wählen oder neu anlegen).
  2. Standplan öffnen → Automatisch verteilen (Paarungen nebeneinander) oder von Hand ändern. Drucken geht direkt dort.
  3. Für die Schießanlage: FLEX-Datei herunterladen (.csv) und im DISAG OpticScore über den FLEX-Import laden.

Fehlen Jahrgang oder Geschlecht, zeigt der Standplan einen Hinweis. Die Angaben stehen im Benutzerprofil.

Ergebnisse eintragen und im RWK melden
  1. Nach dem Wettkampf: im Wettkampf in der Spalte Ringe bei jedem Schützen eintragen → Speichern. Die Ringe der Gegnerschützen genauso.
  2. Ergebnis kopieren → im RWK-Onlinemelder einfügen bzw. abtippen. Der Melder hat keine Schnittstelle, darum dieser Weg.
Gegner verwalten
  1. Oben rechts → Gegner: Vereine, deren Mannschaften und Schützen.
  2. Verein anlegen oder Aus Datei importieren. So musst du Gegnerschützen nur einmal erfassen.
  3. Beim Import ordnest du jeden Verein aus der Datei einem vorhandenen zu oder legst ihn neu an. Vereinsnummern werden gespeichert und beim nächsten Mal erkannt.
  4. Mehrere auf einmal: Vereine anhaken → Zusammenführen in … oder Löschen. Filter oben: nur Nummer, ohne Mannschaft, ohne Schützen, in keinem Wettkampf.

Vereine, die nur als Nummer angelegt wurden, stehen oben unter Bitte zuordnen. Beim Zusammenführen wandern Mannschaften, Schützen und Wettkämpfe mit.

Verwaltung nur Admin

Benutzer anlegen
  1. Benutzer → + Neuer Benutzer.
  2. Name, Benutzername, Rolle, ggf. Pass-Nr., Jahrgang und Geschlecht (für DISAG) → Vorschlag für ein Startpasswort → Speichern.
  3. Benutzername und Startpasswort weitergeben. Beim ersten Login muss das Passwort geändert werden.
Viele Schützen per Datei importieren (CSV)
  1. Verein → Schützen importieren → Datei wählen → Datei prüfen.
  2. Spalten zuordnen. Gibt es eine Vereinsspalte, fragt die App pro Verein: Mitglied, Gegner oder nicht importieren.
  3. So landen nur eure Leute als Benutzer, Gegner in der Gegnerliste.
Mehrere Benutzer auf einmal sperren, löschen, Rolle ändern
  1. Benutzer → oben filtern (z. B. nach Verein, Rolle, „nie angemeldet“).
  2. Haken setzen (oder alle auswählen) → Aktion wählen → Ausführen. Löschen nur mit dem Wort LÖSCHEN.

Wer ausgetreten ist, besser sperren statt löschen. Dann bleiben die Ergebnisse in der Statistik.

Trainingsgruppen und Vereinsdaten
  1. Trainingsgruppen: z. B. Jugend, Erwachsene. Benutzer im Profil zuordnen, Trainings auf Gruppen beschränken.
  2. Verein: Vereinsname, Stände Luftgewehr/Luftpistole und Kleinkaliber, Minuten pro Durchgang (für Standplan und Startzeiten).

Wartung & Server nur Admin

Die Wartungsseite

Alles unter Wartung. Die Ausgabe läuft live mit; es läuft immer nur ein Auftrag.

Sicherung jetztSichert Datenbank, Profilbilder, Einstellungen.
Auf Updates prüfenSucht nur, installiert nichts.
Linux-Updates installierenWie apt full-upgrade, auch Kernel. App läuft weiter.
Alles aktualisierenAlles in einem Lauf: eine Sicherung, Linux-Updates, neue App-Version, Container neu bauen, aufräumen, prüfen (wie sonntags 04:00). Meist der richtige Knopf.
App aktualisierenNeue Version von GitHub holen und einspielen. Vorher Sicherung; startet sie nicht, kommt automatisch die alte zurück.
Container neu bauenOhne neue Version, für aktuelle Sicherheitsupdates im Image.
Server neu startenNach Kernel-Updates. Sonst automatisch um 04:30.
Sicherung einspielen oder App-Version zurückrollen
  1. Sicherung einspielen: Wartung → Abschnitt Sicherungen → gewünschte wählen → EINSPIELEN eintippen. Der jetzige Stand wird vorher noch gesichert.
  2. Zurückrollen: Wartung → App-Version zurückrollen → Version wählen → ZURÜCK eintippen. Daten bleiben erhalten. Wieder nach vorne: App aktualisieren.

Vor jedem Neubau wird automatisch gesichert (die letzten 3 bleiben), dazu täglich um 03:15 (14 Tage) und von Hand (die letzten 5). Linux-Pakete lassen sich nicht zurückrollen, nur App-Versionen.

Neue App-Version und Python-Module
  1. Änderungen kommen über GitHub (Repository der App). Danach in der App App aktualisieren.
  2. Neuere Python-Module (Flask, gunicorn, Pillow …) zeigt Wartung → Versionen orange an. Dependabot schlägt sie auf GitHub vor; nach dem Übernehmen App aktualisieren.
Befehle direkt auf dem Server (SSH)

Nur nötig, wenn die App selbst nicht läuft. Im Ordner /opt/schuetzenverein:

./scripts/status.shÜberblick: App, Sicherung, Updates, Firewall, fail2ban
./update.shApp aktualisieren (--force neu bauen, --rollback <version>)
./scripts/backup.shSicherung jetzt
./scripts/restore.shSicherungen anzeigen / zurückspielen
./scripts/linux-updates.shLinux-Updates installieren
sudo bash scripts/einrichten.shServer-Grundschutz und Zeitpläne einrichten (einmalig, wiederholbar)
docker compose logs --tail 50Letzte Meldungen der App
Wichtige Einstellungen (.env) und Cloudflare
  • TRUST_PROXY=1 und COOKIE_SECURE=1: nötig hinter Cloudflare Tunnel (sonst „kein HTTPS“).
  • SECRET_KEY: eigener Zufallswert (openssl rand -hex 32). Ändern meldet alle ab.
  • BACKUP_DIR: Sicherungsordner, am besten eigenes Laufwerk.
  • Nach Änderungen: docker compose up -d.
  • Kalender-Abos brauchen, dass Google & Co. /kalender/… abrufen dürfen. Blockt Cloudflare (Bot Fight Mode), kommen keine Termine an.
